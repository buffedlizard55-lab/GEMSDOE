# Local mini-ensemble (2026-09-15) - weights experiment, NOT a leaderboard run

Two folds of `configs/config_ci_ensemble.yaml` trained on `data/fixture/` (the real
512x512 competition window) in the dev sandbox, 20 epochs, encoder resnet34,
`pretrained: false` (the weights host is unreachable here).  Purpose: exercise the
parallel-ensemble path end-to-end and measure the fold-weighting choice.

Measured on this 2-fold toy (informational DTI vs the PUBLIC known faults, shaped):

| fold weights | submission DTI | notes |
|---|---|---|
| equal | 0.0143 | fold 0 (held-out 0.150) averaged with fold 1 (held-out 0.049): the weak fold buries the strong one under the t0 floor |
| softmax over held-out DTI (0.691 / 0.309) | 0.0984 | above the blanket-ones floor (0.0955) even with an undertrained toy model |

`--weights dti` is therefore the workflow default (blend step in
`.github/workflows/train-ensemble.yml`).  These numbers characterise the BLENDING
rule only - with 20-epoch models on 24 windows, nothing here says anything about
model quality.  Both reports are machine-generated by scripts/blend_submission.py.
