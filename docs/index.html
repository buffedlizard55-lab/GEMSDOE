1. Problem Overview

Task: Predict geological faults (indicators of geothermal resources) in the GeoDAWN region (NW Nevada & E California, Walker Lane & Great Basin) from multi-channel geophysical data.

Why Faults Matter

Geothermal resources are often hidden where fractures provide pathways for hot fluids. Mapping faults reduces exploration risk. Faults range from tiny to hundreds of miles; surface expression is fault trace, but many are hidden below surface requiring magnetics, gravity, radiometrics, DEM, strain.

Official background: About page

Competition Structure (Unique)

  • Initial Round $50k: Scored on private expert-labeled hidden faults not in USGS database. Top 5 × $10k.
  • Expert Review: Panel uses ALL submissions to find candidate new faults → expanded label set.
  • Final Round $250k: Same submissions rescored on expanded set. Discoveries rewarded: 1st $100k, 2nd $70k, 3rd $40k, 4th $25k, 5th $15k.

Diagram & rules: Problem page #competition-structure and PDF Official Rules

Provided Features (100m, EPSG:32611)

  • Surface conductivity & depth to conductive base (magnetotellurics)
  • Detrended elevation & slope of detrended elevation
  • Dilatation rate, shear strain rate, second invariant
  • Isostatic gravity anomaly & slope
  • Magnetics: reduced-to-pole anomaly, TMI, vertical & horizontal slope of TMI, top-of-crustal magnetic source depth
  • Density of earthquakes
  • Plus 1m_DEM_links.csv for high-res DEM

Source: Provided features section

2. Metric — Distance-Weighted Tversky

From Performance metric section. Tversky index with α=0.2 (FP low penalty), β=0.8 (FN high penalty) → rewards high recall. Triangular kernel R=300m (3 pixels) handles rasterization & misalignment.

k(d) = max(1 - d/R, 0), R=300m
TP_w = Σ_g max_{x:d(x,g)≤R} p(x) k(d(x,g))
FP_w = Σ_x p(x) [1 - max_g k(d(x,g))]
FN_w = Σ_g [1 - max_{x:d(x,g)≤R} p(x) k(d(x,g))]
DTI = TP_w / (TP_w + α FP_w + β FN_w + ε)
0.2
α FP penalty (low)
0.8
β FN penalty (high) → Recall
300m
R = 3px @100m
[0,1]
Submission float32 prob

Implementation: src/metrics.py uses scipy.ndimage.distance_transform_edt and 7×7 max filter for efficient TP/FN.

Insight for leaderboard: Use low threshold (0.1-0.2) to maximize recall. Metric penalizes FN 4× more than FP. Post-processing should connect faults, not remove them.

4. Method — How to Place Top

Reference Solution (Baseline)

Author: John Lipor (Portland State). From GitHub:

  • U-Net, 5 MC splits, patch 128, 5 epochs, Tversky loss α0.2 β0.8, basic [0,1] norm
  • Single model, no TTA, no external DEM, no post-process
  • Estimated LB: ~0.45-0.55 DTI

Our Improvements

  • Data: Robust percentile clipping + standardization, DEM augmentation (slope, curvature, TPI, TRI, detrended, hillshade) from 3DEP
  • Patches: 256px, train_step 32 overlap, hard-negative mining (30% negatives)
  • Aug: RandomResizedCrop 0.5-1.0, flips, rotations, elastic, Gaussian noise
  • Models: Ensemble UNet++, DeepLabV3+, SegFormer with EfficientNet-B5 & MIT-B2 pretrained
  • Loss: BCE + Tversky + Focal Tversky combo, matching metric
  • Train: 10 MC splits, 50 epochs, AdamW, OneCycleLR, early stopping on DTI, mixed precision
  • Infer: Sliding window 50% overlap + Gaussian blend, 8-way TTA, ensemble average
  • Post: Frangi line enhancement, morphological closing, low threshold 0.15 for recall

Architecture Diagram (Conceptual)

Input: (H,W,C) multi-geophysics + DEM derivatives (slope, TPI, TRI, curv, detrended)
  ↓ robust_norm (2-98% clip + standardize)
  ↓ patchify 256 + overlap 32
  ↓ Augment (flip, rot, elastic, resize)
  ↓ Ensemble:
     - UNet++ EfficientNet-B5 (ImageNet)
     - DeepLabV3+ EfficientNet-B5
     - SegFormer MIT-B2
  ↓ Loss: BCE 0.5 + (Tversky 0.5 + FocalTversky 0.5)*0.5  α=0.2 β=0.8
  ↓ Val: distance-weighted Tversky R=300m
  ↓ Inference: sliding window 50% overlap + TTA 8 + ensemble avg
  ↓ Post: Frangi + closing + low thresh 0.15 → prob map
  ↓ Save: GeoTIFF EPSG:32611 100m float32 [0,1] same bounds

Why This Wins Final Round

Final Round rewards discovering true new faults. Our low threshold + line enhancement + DEM lineaments increases recall of subtle hidden faults that experts will verify. We don't overfit to known USGS faults only.

6. Quickstart

git clone https://github.com/buffedlizard55-lab/GEMSDOE.git
cd GEMSDOE

# Env
conda env create -f environment.yml
conda activate gemsdoe
# or pip install -r requirements.txt

# Place data (download from https://www.drivendata.org/competitions/306/competition-doe-gems/data/)
mkdir -p data/
# training_features.tif, labels.tif, sample_submission.tif, 1m_DEM_links.csv

# Optional external
bash scripts/download_external.sh
python scripts/prepare_data.py

# Train (needs GPU)
python -m src.train --config configs/config.yaml

# Inference
python -m src.inference --config configs/config.yaml --model-dir outputs --out submission.tif

# Evaluate
python -m src.metrics --pred submission.tif --true data/labels.tif

Full docs in README.md. Model code in src/.
